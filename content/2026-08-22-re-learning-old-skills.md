---
title: Re-learning old skills in an LLM world
description: A draft on re-learning manual coding skills after going deep on agentic coding.
---

After being in deep in the agentic world these last few months, and having being at my currnet role the last 4 years, coming back to looking for a job has been a bit of a shock. Doing interviews is one thing, talking about my technical background was a matter of collecting my experience as a set of cohesive thoguhts or notes that I could convey. But where things got hard, and to be fair I did expect this, was actually the manual coding aspect.

It wasn't that my technical knowledge had eroded, I felt fully in control of what I was doing like I always have, but it was more just clumsyness -- the muscle memory of writing code by hand had atrohpied and so when i asked those muscles to work again they weren't as sharp as they once were.

For me even doing a simple ternary in React/Typescript, which I have done thousands of times before, didn't come as elegantly as I'd hoped. I got there eventually but it wasn't pretty; even though I had a good grasp of the language, an understanding of the constraints, it was just messy and slow.

So that didn't go well, and I didn't take well, especially given how familiar with the ecosystem I am. So I was determined to do better next time.

So it was clear that I needed to be doing more manual coding. I do think agentic coding is great and helpful with so many things, but it's also really easy to fall in the trap of relying too heavily on it. We need to take a step back now and then and verify if we've fallen into bad habits with it.

So, maybe the tool that caused the problem can also be part of the solution? I needed to practice my manual coding skills to land the right role, but I also think it's a useful to keep our skills sharp, so that we can provide better code reviews, so that we can contribute alongside agents, and so that we can continus understanding their output.

So here's some ways I engaged with LLMs to help with this:

- Producing coding exercises that I could complete, to simulate coding interviews. Initially as full projects I could work on in an editor, but also inline in an agent/chat session.
- Producing projects where I ask the agent to leave parts for me to complete, so I can practice working on actual projects.
- Working as a "virtual flashcard' where it quizzes me on a topic, provides feedback, generates examples, and explains concepts when I get them wrong.

Those were all really helpful, and I think helped to sharpen my skills and prepare me better for not just landing a role, but also a more engaged and motivated human in the workplace, instead of one that was disengaging because I had surrendered too much thinking to the agents.
